## 3. Заголовки: общая картина

| Проблема | Страниц | Где |
|---|---|---|
| Нет H1 | 15 | /events, /quests, /dod, /why_rus, /rus_in_dubai, /teen_camp, /selfgovernment_day, /olympiad_ru, /online_dubai, /russian_online, /summer_intensive, page148947466, page148947596 и др. |
| Больше одного H1 | 2 | /weekends (2), /olympiad_ru_registration (3) |
| H1 не содержит ключевых слов или устарел | 3 | /holidays (даты октября), /about-center («Образовательный цЕНтр»), /dia (нет «Дубай» и «диагностика») |
| H2 стоит раньше H1 | 1 | /courses |
| В заголовок попал абзац текста | 3 | /ru (H3), /about-center (H2), /olympiad_ru_registration (H2 «Дорогие участники…») |
| Пустой заголовок | 2 | /olympiad_ru_registration (пустой H2), /intensives и копии (пустой H3 в форме) |
| H1 есть, H2 нет совсем | 4 | главная `/`, /dia, /holidays, /camp_pay |
| Подзаголовки разделов — `div`, а не H2 | почти все | см. постранично ниже |

**Почему это важно.** H1 — главный сигнал темы страницы для поисковика, H2 — структура разделов, по ним Google строит понимание, на какие подзапросы отвечает страница. Сейчас на большинстве страниц видимые заголовки разделов («Стоимость», «Программа», «Отзывы») сделаны обычным текстом (`div`), и для поисковика у страницы нет структуры.

**Эталон на сайте — /russkiy-online:** один H1, 8 H2 по разделам, H3 внутри. Остальные страницы стоит привести к такой же схеме.

### Как менять тег в Тильде

- **Стандартный блок:** открыть блок → «Контент» → у поля заголовка выбрать тег (H1 / H2 / H3 / обычный текст). В части блоков это в «Настройках» блока, параметр SEO-тега заголовка
- **Zero Block:** выделить текстовый элемент → в панели справа поле тега (H1 / H2 / H3 / div)
- Внешний вид (размер, капс) задаётся стилями отдельно от тега — смена тега не ломает дизайн

### Правила

- Один H1 на страницу, в первом экране, с главным запросом страницы
- H2 — заголовки разделов (5–10 на посадочную страницу), H3 — подпункты внутри раздела
- Не делать заголовками: кнопки, призывы в формах («Запись на консультацию»), абзацы текста, отзывы, названия сквозных блоков («Предстоящие мероприятия центра»)
- Не пропускать уровни: после H1 идёт H2, а не H3
- Капс — стилем, а не набором текста заглавными
